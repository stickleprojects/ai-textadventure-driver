# Feature 58: Merge bidirectional edges in Spatial Matrix

**Status:** Fixed

When two rooms are connected in both directions (e.g. Torch Ghostwood → north → Larch Coppice and Larch Coppice → south → Torch Ghostwood), the pyvis graph draws two separate arrows between them. This doubles the visual clutter for every passable room pair.

**Expected behaviour:**
When both (u → v) and (v → u) edges exist in the world graph, the Spatial Matrix should render a single line with arrows at both ends and a combined label (e.g. `north/south`) instead of two overlapping arrows.

One-way edges (only one direction traversed so far) continue to show a single directed arrow.

**How will we know it's fixed?**
- Paired rooms show one double-headed arrow with a `direction/reverse` label
- Rooms connected in only one direction still show a single arrow
- The Spatial Matrix is visually less cluttered on a large pre-seeded graph
