# Feature 45: No LLM short-circuit for common responses

**Status:** Open

Add a short circuit for common responses so the LLM is not invoked when it isn't needed. If the engine responds with "You can't eat that" we don't need the LLM; if it responds with other text we don't understand, we do.

This can be done via caching but care is needed around responses like "you don't need to use the word 'push' to finish the game" — the prefix is known but the word "push" changes each time.
