# Feature 16: Knight Orc code hardcoded, not in config

**Status:** Fixed

All Knight Orc-specific code was hardcoded in the source rather than declared in a config file, making the agent impossible to repurpose for other games.

**Fix:** `game_config.py` introduces a `GameConfig` singleton; `configs/knight_orc.json` holds creature words, failure phrases, prompt pattern, and inspection sequence.
