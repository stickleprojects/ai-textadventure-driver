# Requirement 27: Verb failures re-learned from scratch each run

**Status:** Fixed

The agent re-learned verb failures from scratch on every run — invalid verb outcomes discovered in one run were not available at the start of the next.

**Fix:** `entity_verb_outcomes` persisted in `knight_orc_strategy.json` (via the `_items.json` sidecar); pre-loaded at startup so subsequent runs skip permanently-invalid verbs immediately.
