# Requirement 44. map features in the ui

**Status:** Open

augment the map in the web ui to support the following:
* search location by name, the user enters the name and clicks a search button, the map brings that node into view and select it or shows a message "cannot find location xxx"
* buttons for moving the map up/down/left/right/zoom
* instructions for mouse actions in the map (mousewheel for zoom, panning, etc)
* straight line edges (currently they are curved)
* select a node and display more information about the node in a seperate panel, any full description we have, inlinks and outlinks, allow the user to click on the inlink or outlink to jump to that node and select it
* allow a single node to be selected, colour it a special colour
* track the current location when the app is stepping through and moving to new locations, beware of teleporting for example we often teleport to the pearly gates when we die - add a checkbox to toggle tracking on or off
* add a button to select the current location


**Effort: Medium | Risk: Low** — to be assessed
