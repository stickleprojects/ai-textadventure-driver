# Requirement 25: No response to route blockages

**Status:** Open

The agent has no way to detect or respond to route blockages reported by the game ("You are blocked by the drawbridge"). These are distinct from hard failures on objects — the verb is valid but a specific obstacle is preventing movement.

**Proposed schema addition:** `blocked_by: [{"obstacle": "drawbridge", "blocking": "route to castle"}]`

**Agent effect:** mark the relevant graph edge as futile OR add as anomaly with `potential_solution: null`.

**Effort: Low | Risk: Low** — schema addition + one new branch in `process_agent_step`.
