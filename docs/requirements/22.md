# Requirement 22: No detection of NPC movement events

**Status:** Open

The LLM extraction schema has no way to detect NPC movement events — NPCs wander independently each game tick and may appear in or leave the current room at any time. Without this, `known_npcs` locations go stale immediately.

**Proposed schema additions:**
- `npc_arrivals: ["Denzyl"]` — NPC appeared in current room
- `npc_departures: [{"npc": "Denzyl", "direction": "north", "destination": "inside"}]` — NPC left; direction and destination both optional

**Agent effects:** arrivals update `known_npcs[npc].location = current_room`; departures mark location stale.

**Effort: Low | Risk: Low** — schema addition + two new branches in `process_agent_step`.
