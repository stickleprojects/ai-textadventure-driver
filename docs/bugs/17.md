# Bug 17: Prompt change to ">" breaks pexpect match

**Status:** Fixed

After a few successful commands, Knight Orc responds with "we won't bother with 'what now' from now on" and the prompt changes to `>` on its own, breaking pexpect matching.

**Fix:** `prompt_pattern` in `game_config.py` and `configs/knight_orc.json` updated to `What now\?|\r?\n>` so pexpect matches both prompts.
