# Bug 59: Compound edge labels grow infinitely

**Status:** Fixed

When two direction aliases ("down" and "out") both reach the same room, `update_graph` merges them into a compound edge label "down/out". `get_next_move_to_target` and the Unknown-exit exploration path then return the full compound label as the action. The game receives "down/out" as a command, fails or behaves unexpectedly, and `update_graph` is called with `action="down/out"`. The dedup check (`action not in existing`) checks whether the compound string is in the individual-label list — it never is — so the label grows: "down/out/down/out", then "down/out/down/out/down/out/down/out", and so on. Within a few steps the action string is thousands of characters long.

**Fix:** Both `get_next_move_to_target` and the Unknown-exit exploration return `label.split("/")[0]` to always emit a single direction word as the action; the compound label is preserved in the graph for reference but only the first alias is ever used as a command.
