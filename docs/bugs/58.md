# Bug 58: Scenery items not in hard failure patterns

**Status:** Fixed

"That's probably just scenery." was not in `hard_failure_patterns` — `take grass` / `take tent` etc. were treated as successful takes, so the agent ran all four inspection verbs (examine, read, look inside) on each scenery item, wasting 3 steps per object and tagging them all `informative`.

**Fix:** Added `"probably just scenery"` to `hard_failure_patterns` in `knight_orc.json`; `take` now fails immediately as `futile`, clears the inspection target, and the remaining verbs are skipped.
