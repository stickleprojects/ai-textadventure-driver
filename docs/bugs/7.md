# Bug 7: Agent doesn't understand failure phrases

**Status:** Fixed

The engine doesn't understand "you can't do that", "you can't see the huge knight", and similar Level 9 refusal responses.

**Fix:** `_is_failure_response()` detects Level 9 refusal phrases and immediately clears the current inspection target so the agent moves on rather than continuing the take/examine/read/look-inside sequence.
