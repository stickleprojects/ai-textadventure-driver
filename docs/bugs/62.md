# Bug 62: Boot/Reset buttons have no guard against misuse

**Status:** Fixed

The "Boot Engine" button can be clicked repeatedly while the engine is already running, spawning orphaned `glklevel9` processes. The "Reset Game & State" button is clickable before any engine has been started, where it has no useful effect (and silently terminates a None process handle).

**Expected behaviour:**
- Boot Engine is enabled only when no engine is running; disabled once one is.
- Reset Game & State is disabled by default; enabled only after the engine has been booted.

**How will we know it's fixed?**
- With no engine started: Boot is enabled, Reset is greyed out.
- After clicking Boot: Boot becomes greyed out, Reset becomes enabled.
- After clicking Reset: Boot becomes enabled again, Reset becomes greyed out.
