# Bug 19: Crash on use command with None node

**Status:** Fixed

After `use putty knife on rubbish` the agent crashed with `ValueError: None cannot be a node` and then repeated the same command in a loop.

**Fix:** `extracted.get("room")` replaces `"room" in extracted` so null values don't corrupt `state["current_room"]`; `update_graph` gains an early-return guard for None room; goal hard-failure removes anomaly from queue.
