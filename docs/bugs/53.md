# Bug 53: Unknown nodes clutter map at full size

**Status:** Fixed

Unknown placeholder nodes ("? west", "? south" etc.) used full box shape and size, cluttering the map equally with explored rooms.

**Fix:** Unknown nodes now render as small grey circles (`_MAP_UNKNOWN_SIZE = 300`) with label `"?"` only; `_display_label` simplified to return `"?"` for all Unknown nodes.
