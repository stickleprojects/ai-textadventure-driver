# Bug 13: Model non-deterministically returns empty extraction

**Status:** Fixed

The eval suite (`tests/test_evals.py`) found the quantized Phi-3.5-mini model non-deterministically returns `{}` for short inputs.

**Fix:** `extract_knowledge` retries up to 3 times on empty result; prompt updated with two few-shot examples and explicit rules for terse take confirmation and exits extraction.
