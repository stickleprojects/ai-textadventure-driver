# Bug 42: Crash on null list fields from LLM

**Status:** Fixed

Crash at step 19 of run watch_20260701_123641: `'NoneType' object is not iterable` near "You don't need to use the word rodents…". Root cause: LLM returns `null` for list fields (e.g. `"npcs": null`); `dict.get(key, [])` returns `None` rather than `[]` when the key is present with a null value. Stack trace was also missing from the log.

**Fix:** `extract_knowledge` normalises any non-list value for the seven list fields to `[]` after JSON parse; crash handler in `watch_run.py` now records `traceback.format_exc()` in the log entry and stderr.
