# Bug 50: Article variations create duplicate graph nodes

**Status:** Fixed

LLM returns slight article variations for the same room name ("cave in juniper scrubland" vs "cave in a juniper scrubland"), creating duplicate nodes on the graph.

**Fix:** `_resolve_room_name` normalises by stripping articles and lowercasing before comparing against existing nodes; if a match is found the existing node name is reused. Called at the `state["current_room"]` assignment in `process_agent_step` and in the `rebuild_graph` replay script.
