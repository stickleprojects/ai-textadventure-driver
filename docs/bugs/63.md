# Bug 63: TypeError crash on first step when boot LLM extraction returns null room

**Status:** Fixed

**Steps to reproduce:**
1. Run the Streamlit UI — the Spatial Matrix is pre-filled with locations from the strategy file
2. Click "Boot Engine (Start Game)" — the first room description renders in the I-O Terminal
3. Click "Step Once" — crash:

```
File "app.py", line 154, in <module>
    process_agent_step(state, child, llm)
File "agent.py", line 413, in process_agent_step
    action_taken, action_reason = determine_next_action(state)
File "agent.py", line 352, in determine_next_action
    if path_len < best_len:
       ^^^^^^^^^^^^^^^^^^^
TypeError: '<' not supported between instances of 'dict' and 'float'
```

**Root cause:**

The boot extraction in `app.py` uses `if "room" in extracted_init:` which fires even when the LLM returns `{"room": null, ...}`, setting `state["current_room"] = None`.

`determine_next_action` then reaches the "navigate to nearest unvisited room" branch (enabled because `_make_clean_state()` now pre-seeds the world graph from strategy). Inside the loop, `nx.shortest_path_length(G, None, node)` is called with `source=None`; NetworkX interprets this as "compute paths from all sources" and returns a `dict` instead of raising `NodeNotFound`. The subsequent `dict < float("inf")` comparison crashes.

Before `_make_clean_state()` started loading the world graph, the loop had no iterations and the crash never triggered.

**Fix:**
- In `app.py`: change `if "room" in extracted_init:` to `if extracted_init.get("room"):` — consistent with how `process_agent_step` already handles this (line 451)
- In `agent.py`: guard the "navigate to unvisited room" loop against `current_room` being `None` or absent from the graph, as a defensive fallback

**How will we know it's fixed?**
- Boot the UI with a cloud or local LLM, click Step Once — no crash, agent issues a `look` or navigation command
- Manually setting `state["current_room"] = None` before Step Once also produces a `look` fallback rather than a crash
