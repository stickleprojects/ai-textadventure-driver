# Bug 49: Non-cardinal directions missing from reverse map

**Status:** Fixed

Non-cardinal directions ("in", "out") were missing from `_REVERSE`, so traversal via "in" skipped placeholder cleanup entirely — Unknown nodes were never removed and no real edge was added.

**Fix:** "in"/"out" added to `_REVERSE`; BFS layout treats "in" as z−1 (sub-space band, same as "down") and "out" as z+1. Merged edge labels are split on "/" before taking the first token for BFS positioning.
