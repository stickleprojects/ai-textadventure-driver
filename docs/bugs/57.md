# Bug 57: LLM returns full description as room name

**Status:** Fixed

LLM returns the full room description instead of just the short name on some visits — "a dingy stable, a temporary building with canvas walls and lots of straw" vs "a dingy stable" — causing the same physical room to be stored as multiple graph nodes. The agent treats each variant as an unvisited room and oscillates between a small cluster of already-explored rooms for 100+ steps, tagged `productive` because the room does change each step.

**Fix:** `_short_room_name()` truncates at the first comma or semicolon and strips trailing period before any other normalisation; both `_normalize_room` (matching) and `_canonicalize_room` (node storage) call it, so all description variants collapse to the same short key.
